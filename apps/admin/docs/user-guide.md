# Инструкция по работе с админкой

**Адрес:** https://admin.snzbeachvolleyball25.ru

---

## Вход в систему

Откройте сайт в браузере, введите логин и пароль.
Сессия действует 24 часа — после этого нужно войти снова.

---

## Роли

В системе две роли:

| Роль | Возможности |
|------|------------|
| **Редактор** | Создавать и редактировать черновики статей и врачей |
| **Администратор** | Всё то же самое + публикация, управление пользователями, настройки |

---

## Структура контента

```
Животное (например: Кошка 🐱)
  └── Категория (например: Отравление ☠️)
       └── Статья (например: Что делать при отравлении)

Врач (ФИО, фото, специализация)
  └── Расписание (дни недели + время)

Грумер
  └── Коллекция пород (порода, время стрижки, цена)
  └── Шаблон рабочей недели
  └── Записи на конкретные даты
```

## Животные

Раздел **«Животные»** в левом меню.

### Добавить животное
1. Нажмите **«Добавить»**
2. Введите название, slug, иконку-эмодзи, порядок сортировки
3. Нажмите **«Сохранить»**

---

## Категории

Раздел **«Категории»** — сгруппированы по животным, нажмите на животное чтобы раскрыть.

---

## Статьи

Раздел **«Статьи»** в левом меню.

### Добавить статью
1. Нажмите **«Добавить»**
2. Введите **заголовок** — slug заполнится автоматически
3. Напишите текст в редакторе
4. Отметьте нужные **категории**
5. Нажмите **«Сохранить»**

### Статусы статей
- **Черновик** — видна только в админке, в боте не отображается
- **Опубликована** — видна пользователям в боте

Кнопка публикации доступна только администратору.

---

## Врачи

Раздел **«Врачи»** в левом меню.

### Добавить врача
1. Нажмите **«Добавить»**
2. Заполните **ФИО** (обязательно), специализацию, описание, контакты
3. Нажмите **«Сохранить»**
4. После сохранения загрузите **фото** (JPG/PNG/WebP, до 5 МБ)

### Расписание врача
В карточке врача в блоке **«Еженедельное расписание»** выберите день, время начала и конца.
В **«Исключениях»** можно задать на конкретную дату: выходной или изменённый график.

---

## Расписание клиники

Раздел **«Расписание»** — общий вид расписания всех врачей на период.
Администратор может настроить период отображения (1–5 недель или месяц).

## Груминг

Раздел **«Груминг»** в левом меню.

### Таб «Коллекция пород»

Содержит список животных/пород, которых принимает грумер. Для каждой записи указывается:
- **Порода** — название породы или вида животного
- **Время стрижки** — продолжительность в минутах (используется для расчёта записи в расписании)
- **Стоимость** — необязательно
- **Описание** — что включает услуга

### Таб «Расписание» → «Шаблон недели»

Задаёт рабочие дни и часы работы грумера на каждую неделю.

1. Включите нужные дни переключателем
2. Задайте время начала и конца работы
3. Изменения сохраняются автоматически

Записи можно создавать только в те дни и часы, которые указаны в шаблоне.

### Таб «Расписание» → «Записи»

Показывает месячный календарь. Рабочие дни отображены активными, нерабочие — серыми.

**Как создать запись:**
1. Нажмите на рабочий день в календаре
2. Внизу откроется тайм-лайн дня с визуальной сеткой
3. Наведите на свободный слот → появится кнопка «+» с временем
4. Нажмите на слот или кнопку «Добавить запись»
5. Выберите породу из коллекции, введите кличку и телефон хозяина
6. Нажмите **«Записать»**

Запись автоматически займёт время согласно продолжительности стрижки. Если время уже занято, система покажет ошибку.

**Удаление записи:** нажмите иконку корзины на блоке записи в тайм-лайне.

## Пользователи

Раздел **«Пользователи»** — только для администратора.

### Добавить пользователя
1. Нажмите **«Добавить»**
2. Введите логин, пароль, выберите роль
3. Нажмите **«Создать»**

## Частые вопросы

**Как статья попадает в бот?**
Только после публикации — нажмите кнопку публикации (только для администратора).

**Если ушёл со страницы не сохранив — данные потеряются?**
Система предупредит перед уходом — появится диалог подтверждения.

**Забыл пароль?**
Обратитесь к администратору — он создаст новый аккаунт.

**Что такое slug?**
Техническое название на латинице, используется в адресе. Менять slug существующих записей не рекомендуется.
