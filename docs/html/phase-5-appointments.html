Клиент: запись и задать вопрос в Mini App; отдельно — мобильное приложение «Ветпрактика» (вход TG/VK в APK, запись — позже). Staff: admin «Запись» + один чат врачей. Ответ на вопрос — «Ответить» или reply → личка клиента в боте.

Mini App — запись (C1)

  • Услуга → день → при УЗИ время (time_slots)
  • На сегодня не показываются прошедшие часы
  • Мои заявки: вкладки «Активные» / «Архив», отмена своей заявки
  • Лимиты: кличка, слот, настраиваемые потолки в rules

Mini App — вопрос (Q1)

  • Главная → Задать вопрос (10–2000 символов, до 5 в день)
  • Сообщение в тот же staff_chat_id, что и заявки
  • Врач: кнопка «Ответить» или reply на пост бота
  • Клиент получает ответ в личку бота

BotFather: Group Privacy → Disable (чтобы бот видел reply в группе).

Мобильное приложение (M-mobile)

  • Отдельный канал RuStore «Ветпрактика» — не Mini App
  • Вход: Telegram OTP ✅ на APK; VK ID — Web-приложение + vk-callback.html на app.snzbeachvolleyball25.ru
  • Профиль и выход — вкладка «Ещё»
  • Запись — тот же API, что Mini App; в разработке (sprint 5)
  • APK: npm run build → npx cap sync android
