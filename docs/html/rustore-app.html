Порядок действий (первый раз)

1. Аккаунт разработчика

  1. Зарегистрироваться в RuStore Консоль (VK ID).
  2. Для бесплатного приложения без покупок внутри — часто хватает аккаунта физлица.
  3. Монетизация через RuStore — ИП/юрлицо, часто ЭЦП / VK Бизнес ID.

2. Карточка приложения

  1. Консоль → Приложения → Добавить приложение
  2. Название: Ветпрактика
  3. Загрузить версию
  4. Package name = ru.snzbeachvolleyball25.vetpraktika

3. Загрузка и модерация

RuStore принимает APK и AAB. Для AAB подпись настраивается до загрузки. После загрузки — описание, скриншоты, privacy policy → отправка на модерацию (ориентир ~1 ч, закладывайте 1–3 дня).

Keystore — файл подписи и пароли храните отдельно от git. Потеря = невозможность обновлять то же приложение.

Сборка Android (наш проект)

cd apps/mobile
cp .env.example .env.local
npm run build
npx cap sync android
npx cap open android

В Android Studio: Build → Generate Signed Bundle / APK → рекомендуется AAB.

Capacitor: capacitorjs.com/docs/android ↗

Материалы для модерации

  • Иконка 512×512, adaptive icon
  • Скриншоты (мин. 2): главная, запись, статья
  • Краткое и полное описание
  • Категория: здоровье / медицина
  • URL политики конфиденциальности
  • Контакты поддержки (телефон/email клиники)
  • Согласие на ПДн в форме записи в приложении

Тест входа и записи

  1. Пользователь открывает бота с start=link → «Поделиться номером»
  2. В приложении: телефон → код в Telegram → JWT
  3. Запись через API /api/mobile/v1/.../booking/requests (после deploy server, миграция 019)
